# 分享文档

本目录包含基于 CS336 深度学习系统学习项目整理的专题分享文档，采用**PPT演讲风格**设计，每个专题提供两个版本：

- **30分钟精华版**: 核心概念速览，适合快速分享和入门
- **60分钟深度版**: 完整技术解析，适合专题研讨和深入学习

## 文档特点

### PPT演讲风格
- 每页一个核心观点
- 清晰的视觉层次 (`---` 分隔页面)
- 简洁的代码示例
- 便于记忆的数字和对比表

### 时长设计
| 版本 | 时长 | 用途 |
|------|------|------|
| 30分钟 | 含Q&A | 团队技术分享、快速科普 |
| 60分钟 | 含10min Q&A | 专题研讨、深度培训 |

### 内容结构

**30分钟版**:
```
1. 为什么重要？   (3 min)
2. 核心概念       (8 min)
3. 关键技术点     (10 min)
4. 实战案例       (5 min)
5. 总结           (2 min)
6. Q&A           (2 min)
```

**60分钟版**:
```
Part 1: 背景与动机          (5 min)
Part 2: 核心原理深度解析    (20 min)
Part 3: 实现细节与代码      (15 min)
Part 4: 高级话题与优化      (10 min)
Part 5: 实战案例分析        (5 min)
Part 6: 总结与讨论          (5 min)
Q&A                         (10 min)
```

## 如何使用

### 作为演讲材料
1. Markdown文件可直接导出为Slides (推荐使用 Marp, reveal.js)
2. `---` 分隔符自动生成分页
3. 代码块和表格会正确渲染

### 作为学习材料
1. 按专题顺序阅读
2. 结合 `学习笔记/` 中的详细讨论
3. 运行 `experiments/` 中的代码验证

### 自定义分享
1. 复制模板: `_模板/30分钟分享模板.md`
2. 按结构填充内容
3. 调整时间分配
