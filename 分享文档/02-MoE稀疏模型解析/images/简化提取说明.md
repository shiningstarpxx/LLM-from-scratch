# 最简单的提取方法

## 方法1：使用一键脚本（推荐）

运行以下命令，会自动下载PDF并打开：

```bash
cd images
./一键打开PDF.sh
```

然后：
1. PDF会自动打开
2. 找到架构图（通常在Figure 1或前3页）
3. 使用 `Command + Shift + 4` 截图
4. 保存为PNG格式，直接覆盖 `images/` 目录下的占位图片

## 方法2：手动下载和提取

1. **下载PDF**：
   - Shazeer 2017: https://arxiv.org/pdf/1701.06538.pdf
   - Switch 2021: https://arxiv.org/pdf/2101.03961.pdf
   - Mixtral 2024: https://arxiv.org/pdf/2401.04088.pdf

2. **打开PDF**，找到架构图

3. **截图保存**，覆盖以下文件：
   - `images/shazeer2017.png`
   - `images/switch2021.png`
   - `images/mixtral2024.png`
