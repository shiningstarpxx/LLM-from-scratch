# 图片获取说明

## 5张图片的获取方式

### ✅ 可以从论文PDF中提取（3张）

1. **shazeer2017.png** - Shazeer 2017
   - 论文：https://arxiv.org/pdf/1701.06538.pdf
   - 位置：Figure 1 或前3页

2. **switch2021.png** - Switch Transformer
   - 论文：https://arxiv.org/pdf/2101.03961.pdf
   - 位置：Figure 1 或前3页

3. **mixtral2024.png** - Mixtral 8x7B
   - 论文：https://arxiv.org/pdf/2401.04088.pdf
   - 位置：Figure 1 或前3页

### 🌐 可以从网页获取（1张）

4. **moe_transformer_layer.png** - MoE Transformer Layer综合架构图
   - **方法1**：Mixtral官方博客
     - 访问：https://mistral.ai/news/mixtral-of-experts/
     - 找到架构图，截图保存
   
   - **方法2**：Hugging Face文档
     - 访问：https://huggingface.co/docs/transformers/main/en/model_doc/mixtral
     - 找到架构图，截图保存
   
   - **方法3**：使用Mixtral论文中的架构图
     - 从 mixtral2024.pdf 中提取相关架构图

### 📚 需要特殊处理（1张）

5. **jacobs1991.png** - Jacobs 1991原始MoE架构图
   - **问题**：1991年的论文，可能不容易在线获取
   
   - **解决方案1**：使用简化版本
     - 这个架构图相对简单，可以用文字描述替代
     - 或者使用文档中已有的ASCII艺术图
   
   - **解决方案2**：从学术数据库获取
     - ResearchGate: https://www.researchgate.net/publication/220116500_Adaptive_Mixtures_of_Local_Experts
     - 需要注册账号下载
   
   - **解决方案3**：暂时保留占位图
     - 这个架构图不是核心，可以暂时使用占位图

## 推荐操作顺序

### 优先级1：3篇论文的架构图（必须）
1. 从已打开的PDF中提取 shazeer2017.png
2. 从已打开的PDF中提取 switch2021.png  
3. 从已打开的PDF中提取 mixtral2024.png

### 优先级2：综合架构图（重要）
4. 从Mixtral博客或Hugging Face获取 moe_transformer_layer.png

### 优先级3：Jacobs 1991（可选）
5. 如果找不到，可以暂时保留占位图，或使用文档中的文字描述

## 快速获取脚本

运行以下命令会自动打开所有资源：

```bash
cd images
./一键打开PDF.sh
# 然后手动访问：
# - https://mistral.ai/news/mixtral-of-experts/
# - https://huggingface.co/docs/transformers/main/en/model_doc/mixtral
```
