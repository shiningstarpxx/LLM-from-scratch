# MoE架构图提取指南

## 快速开始

文档已配置为使用本地图片。请将以下图片文件放到 `images/` 目录下：

1. `jacobs1991.png` - Jacobs 1991原始MoE架构图
2. `shazeer2017.png` - Shazeer 2017稀疏门控MoE架构图  
3. `switch2021.png` - Switch Transformer架构图
4. `mixtral2024.png` - Mixtral 8x7B架构图
5. `moe_transformer_layer.png` - MoE Transformer Layer完整架构图

## 方法1：从PDF中手动提取（推荐）

### 步骤1：下载论文PDF

- **Shazeer 2017**: https://arxiv.org/pdf/1701.06538.pdf
- **Switch Transformer**: https://arxiv.org/pdf/2101.03961.pdf
- **Mixtral**: https://arxiv.org/pdf/2401.04088.pdf
- **Jacobs 1991**: 需要从学术数据库下载

### 步骤2：提取图片

**使用Mac预览（Preview）**：
1. 打开PDF文件
2. 找到架构图页面
3. 使用 `Command + Shift + 4` 截图
4. 或使用工具 > 选择工具，框选图片区域，然后复制
5. 粘贴到预览，保存为PNG格式

**使用Adobe Reader**：
1. 打开PDF
2. 工具 > 编辑PDF
3. 选择图片，右键 > 复制图像
4. 粘贴到图片编辑软件，保存为PNG

**使用在线工具**：
- https://www.ilovepdf.com/extract-images-from-pdf
- https://smallpdf.com/extract-images-from-pdf

### 步骤3：重命名并保存

将提取的图片重命名为对应的文件名，保存到 `images/` 目录。

- **格式**：PNG（推荐）或JPG
- **分辨率**：至少800像素宽度，确保清晰
- **命名**：严格按照上述文件名
- **位置**：必须放在 `images/` 目录下

## 常见问题

**Q: 图片在PDF中不显示？**
A: 检查：
1. 图片文件是否在 `images/` 目录下
2. 文件名是否完全匹配（区分大小写）
3. 使用 `--allow-local-files` 参数

**Q: 图片质量不够？**
A: 尝试：
1. 从PDF中直接提取，而不是截图
2. 使用高分辨率设置
3. 保存为PNG格式

**Q: 找不到某个论文的架构图？**
A: 
- Jacobs 1991: 可能需要从学术数据库获取
- 其他论文: 通常在前3页的Figure中
