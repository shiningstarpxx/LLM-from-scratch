## 🔄 替换方法

### 方法1：从PDF中提取（推荐）

1. **下载论文PDF**：
   ```bash
   cd images
   ./快速提取.sh
   ```

2. **打开PDF文件**（在 `/tmp/moe_images/` 目录）：
   - `shazeer2017.pdf`
   - `switch2021.pdf`
   - `mixtral2024.pdf`

3. **提取架构图**：
   - 使用Mac预览（Preview）打开PDF
   - 找到架构图页面（通常在Figure 1或前3页）
   - 使用 `Command + Shift + 4` 截图
   - 或使用工具 > 选择工具，框选图片区域，复制后粘贴到预览
   - 保存为PNG格式，**直接覆盖**对应的占位图片文件

4. **替换文件**：
   - 将提取的图片保存为对应的文件名
   - 直接覆盖 `images/` 目录下的占位图片
