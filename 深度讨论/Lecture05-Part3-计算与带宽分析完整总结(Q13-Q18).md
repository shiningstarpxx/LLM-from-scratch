### 精确定义

```python
Arithmetic Intensity (AI) = FLOP / Bytes

单位: FLOP/Byte
含义: 每读写1字节数据，能做多少次浮点运算
别名: 算术强度、计算密集度

核心思想:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
高AI = 数据被充分利用 = 计算密集 ✅
低AI = 数据利用不足 = 内存密集 ❌

优化目标:
提升AI，让每个字节产生更多价值！⭐
```

## 💡 Q15: Roofline Model

### 核心概念

```python
Roofline Model = 性能上限的可视化图表

核心思想:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
给定硬件规格:
- 计算能力: Peak FLOP/s
- 内存带宽: Peak Bandwidth

任何程序的实际性能不能超过两个限制:
1. 计算限制: Peak FLOP/s
2. 内存限制: Bandwidth × AI

Roofline = 这两个限制形成的"屋顶"线
```

### Roofline 公式

```python
实际性能 ≤ min(Peak_FLOP, Bandwidth × AI)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
情况1: AI很低 (Memory-Bound)
Performance = Bandwidth × AI
→ 性能由内存带宽限制

情况2: AI很高 (Compute-Bound)  
Performance = Peak_FLOP
→ 性能由计算能力限制

转折点: AI_critical = Peak_FLOP / Bandwidth
→ Q13学的 208 FLOP/Byte! ✅
```

### 实战应用

```python
在Roofline图上,每个kernel的位置告诉我们:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 水平位置 (AI)
   - 左边 (AI低): Memory-Bound
   - 右边 (AI高): Compute-Bound
   
2. 垂直位置 (Performance)
   - 贴近Roofline: 优化得好 ✅
   - 远离Roofline: 有优化空间 ❌
   
3. 到Roofline的距离
   - 距离 = 理论性能 - 实际性能
   - 距离越大 → 优化潜力越大
   
4. 优化方向
   - Memory-Bound kernel: 向右移动 (提升AI)
   - Compute-Bound kernel: 向上移动 (算法优化)
```

### N²问题的精确分析

```python
标准Attention的内存爆炸:

关键问题 (学员说的！):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### FlashAttention的Tiling解决方案

```python
学员的核心洞察: "tile把Q, K拆开，这样只跟N相关，不再是二次方关系"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Tiling策略:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 把Q分成多个tiles
Q_tiles = [Q[0:64], Q[64:128], ..., Q[1984:2048]]  # 32个tiles
K_tiles = [K[0:64], K[64:128], ..., K[1984:2048]]  # 32个tiles

# 只计算部分S矩阵！
```

### FlashAttention就是Fusion!

```python
学员的理解连接:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FlashAttention = Tiling + Fusion!

标准Attention:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Kernel 1: S = Q @ K.T
Kernel 2: P = softmax(S)
Kernel 3: O = P @ V

3个独立kernels ❌

FlashAttention:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# Tiling (空间维度)
for tile_q in tiles(Q):
    for tile_k, tile_v in tiles(K, V):
        # Fusion (时间维度)
        tile_s = tile_q @ tile_k.T      # 在SRAM
        tile_p = softmax(tile_s)        # 在SRAM (不写HBM!)
        tile_o = tile_p @ tile_v        # 在SRAM (不写HBM!)
        accumulate(tile_o)

1个kernel，3个操作融合！✅

学员的组合理解完美解释了FlashAttention！⭐⭐⭐⭐⭐
```
